# Curious Farm demo

A public preview of Curious Farm, a game prototype for children aged 8 to 12.

Live page: https://lexi-le-xi.github.io/curious-farm-demo/

This repository holds built static files only. The demo has no AI: cards for new questions can't be written here, and all conversations in it are made-up examples. The starting questions have ready-made cards that have not yet had a human fact check. Progress stays in your own browser, and nothing you type is sent anywhere.
