# Curious Farm demo

A public preview of Curious Farm, a game prototype for children aged 8 to 12.

Live page: https://lexi-le-xi.github.io/curious-farm-demo/

This repository holds built static files only. The demo has no AI: the sprite uses scripted lines, and all conversations in it are made-up examples. Progress stays in your own browser, and nothing you type is sent anywhere.
